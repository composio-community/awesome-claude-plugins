# Plumbward Lite

Two skills, free, no setup. They work the moment you install them.

## What you get

**Never lose work to a "clean up"**
Before anything is deleted, moved, or overwritten, you see the exact list of files — with the recently-edited and unusually-large ones flagged. It prefers moving things to a `_to_delete/` folder over deleting them, and it writes a log of what actually happened.

**Stop burning through your limits**
Cuts the habits that quietly cost you: re-reading files that are already in context, stacking corrections instead of revising the original request, leaving unused connectors switched on, and running one endless session instead of checkpointing and restarting.

## Setup

None. Install it and it applies.

## What's not in here

Lite doesn't know anything about *you*. The full version runs a short interview and writes a profile — how you write, what Claude keeps getting wrong for you, what it should never do without asking — and every skill reads it. That's where voice capture, session checkpointing, and source verification live.
